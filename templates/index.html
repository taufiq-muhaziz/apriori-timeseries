Ruang Lingkup Sistem
Tujuan Aplikasi

Aplikasi ini dibangun untuk membantu proses analisis data transaksi penjualan. Sistem digunakan untuk menemukan pola pembelian konsumen, memprediksi penjualan produk, dan menghasilkan rekomendasi pengelolaan stok menjelang Lebaran.

Sumber Data

Data yang digunakan berupa data transaksi penjualan dan data penjualan harian dalam format CSV. Struktur kolom harus sesuai dengan kebutuhan masing-masing proses analisis.

Alur Pemrosesan Data Penelitian
1. Input Dataset

Pengguna mengunggah data transaksi atau data penjualan harian dalam format CSV.

2. Analisis Apriori

Sistem menghasilkan aturan asosiasi produk berdasarkan nilai support, confidence, dan lift.

3. Analisis Time Series

Sistem mengevaluasi tiga model dan menggunakan ARIMA untuk memprediksi penjualan selama 90 hari.

4. Rekomendasi Stok

Sistem menghasilkan prioritas penambahan stok, stok dipertahankan, serta stok minimum atau normal.
