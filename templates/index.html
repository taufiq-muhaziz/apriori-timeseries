Ruang Lingkup Sistem
Tujuan Aplikasi

Sistem komputasi ini dibangun untuk mengolah data riwayat transaksi penjualan ritel secara digital. Melalui pendekatan data-driven, sistem mengekstrak pengetahuan tersembunyi mengenai keterkaitan antar produk serta proyeksi angka kebutuhan stok barang di masa yang akan datang.

Sumber Data Input

Format berkas yang didukung oleh sistem pemrosesan ini wajib berupa file data berwujud koma atau komparasi sejenis bertipe format .CSV (Comma Separated Values).

Arsitektur Alur Pemrosesan Data Penelitian
1. Input Dataset

User mengunggah file transaksi penjualan mentah berformat .csv ke dalam sistem.

2. Analisis Apriori

Mengekstrak aturan asosiasi untuk mengetahui kombinasi item yang dibeli bersamaan.

3. Peramalan Deret Waktu

Memproyeksikan kuantitas kebutuhan stok masa depan lewat ARIMA, SARIMA, & Prophet.

4. Hasil Rekomendasi

Sistem memformulasikan aksi operasional: Restock, Maintain, atau Cuci Gudang.
